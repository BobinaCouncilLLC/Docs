# Docs images

Gallery art in `bobinas/` is copied from the public [bobina.moe gallery](https://bobina.moe/bobinas). Each file is `{id}-{title}.webp` and every docs use of it links back to `https://bobina.moe/bobinas/{id}` as the source.

Screenshots in `docs/` are local copies of the command examples and the Discord mark. They used to be loaded from the site instead of this repo.

Files are resized WebP so the docs repo does not depend on the live site for images.
